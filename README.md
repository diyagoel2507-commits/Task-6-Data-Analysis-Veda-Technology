# Day 6 – Excel Formulas & Functions Fundamentals

## Overview

This project focuses on practicing core Excel formulas and functions used in everyday data analytics.

## Tools Used

- Microsoft Excel

## Excel Functions Practiced

- VLOOKUP
- XLOOKUP
- IF
- SUMIF
- SUMIFS
- COUNTIF
- COUNTIFS
- UPPER
- LEFT
- LEN
- INDEX + MATCH

## Workbook Structure

1. Transactions
2. Products
3. Customers
4. Summary
5. Notes

## Work Performed

- Product information lookup using VLOOKUP and XLOOKUP
- Revenue calculation
- Order status classification using IF
- City-wise revenue analysis
- Online revenue analysis
- Order counting using COUNTIF and COUNTIFS
- Text manipulation using UPPER, LEFT and LEN
- Flexible lookup using INDEX and MATCH
- Formula testing with edge cases
- Short notes on when to use each formula

## Key Results

- Delhi Revenue: ₹4,850
- Mumbai Revenue: ₹3,300
- Delhi Online Revenue: ₹3,150
- Delhi Orders: 6
- Delhi Online Orders: 4

## Learning Outcome

Learned how to use Excel formulas and functions to transform transactional data into useful business insights and summaries.

## Interview Preparation

The project also includes short notes covering the differences between SUMIF and SUMIFS, XLOOKUP and VLOOKUP, and when to use INDEX/MATCH.
